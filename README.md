# Mohammed Hossam — Portfolio

Personal branding website for Mohammed Hossam, Cloud DevOps Engineer | Software Developer.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Node.js/Express API (planned as the next phase)
- Docker
- Kubernetes
- GitHub Actions
- AWS EC2 / ECR
- Argo CD (deployment phase)

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Project structure

- `app/` — Next.js pages and global styling
- `components/` — reusable UI sections
- `data/` — portfolio content; edit these files to update the website
- `public/cv/` — your CV PDF
- `k8s/` — Kubernetes manifests added in the deployment phase
- `.github/workflows/` — CI/CD workflows added in the deployment phase
